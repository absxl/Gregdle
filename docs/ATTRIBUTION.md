## GTNH machines dataset (`data/gtnh/machines.json`)

- Source: [GT New Horizons Wiki](https://wiki.gtnewhorizons.com) — MediaWiki 1.46.2 (Miraheze).
- Pages fetched politely (identified User-Agent, ~1 request/2s, cached locally) on 2026-11-03;
  snapshot of the wiki's default render (GTNH 2.9).
- Each entry carries its `source_url` pointing back to the wiki page it came from.
- Machine texture images are hot-linked from the wiki's static asset host
  (`static.wikitide.net`) and remain the property of the GTNH project / their authors.
- Quality report: `data/gtnh/machines-quality.md`.
